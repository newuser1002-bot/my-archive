# 추가 Figma 원본 대조 — 2026-10-29

제공받은 Figma Make 원본 App.tsx의 RecordForm·RatingInput·genreOptions·저장 흐름과 index.css를 읽었다. 원본은 수정·실행하지 않았다. AGENTS.md의 서버 실행 안내는 Figma 환경용이며 현재 로컬 상태로 간주하지 않는다.

개발 기준은 GitHub 팀 코드다. 원본은 숫자 ID, type(한글), memories/date/quote/body/photo 및 screen state를 사용하지만 팀은 문자열 ID, category, reviews/viewedAt/shortReview/story/photoUrl 및 React Router를 사용한다. App.tsx나 저장 코드를 통째로 덮어쓰지 않는다. 원본 localStorage 코드가 팀 A의 공통 저장 모듈 제공을 뜻하지 않는다.

## 승인 및 반영 결과

사용자가 ‘반영해’로 승인했다. GitHub 형식을 유지하면서 아래 기능을 B에 반영했다.

- 유형별 장르 선택과 유형 변경 시 장르 초기화, 영화 기본 선택.
- 제공 원본의 SVG 경로를 재사용한 유형/사진/별점 아이콘, 선택 작품 미니 카드와 톤, 둥근 입력창·헤더·제목 스타일.
- 원본처럼 새 별점 입력은1~5점 버튼, 별점 지우기 제공. 기존4.5 등 반점 기록은 그대로 표시·저장 가능하며 정수 버튼을 누를 때만 변경.
- 새 한줄평80자 제한과 글자 수 표시. 기존80자 초과 기록은 자동 자르지 않으며, 그대로 두면 다른 필드만 수정할 수 있고 한줄평을 바꾸면80자 이내로 정리.

## 대조했던 차이 (반영 전 기록)

- 원본: 유형별 장르 선택 목록. 현재 B: 장르 직접 입력.
- 원본: 유형 아이콘·카드형 선택 작품·더 둥근 입력창 등. 현재 B는 이전 공개 시안과 팀 레이아웃 기준이므로 추가 대조 가능.
- 원본: 정수 별점 버튼이나 샘플은 4.5 포함. 현재 B: 0.5 간격. 반점 지원 유지 여부 확인.
- 원본: 한줄평 최대80자. 현재 B: 임의 제한 없음. 제한 적용·기존 초과 기록 처리는 승인 후 반영.

## 원본을 그대로 가져오지 않을 부분

- 날짜 2025-03-22 고정값 대신 B의 실제 로컬 날짜 유지.
- 원본의 임시 Blob URL 저장을 영구 사진 복원 방식으로 사용하지 않는다. B의 사진 전처리/URL 해제와 A 저장 연계 유지.
- 원본 수정 화면의 삭제 기능은 팀 역할상 C 담당이므로 B에 추가하지 않는다.
- 홈·상세·공유·통계와 Figma 전용 Vite 플러그인은 가져오지 않는다.
